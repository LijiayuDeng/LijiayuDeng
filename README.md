I am a student in [the Wen Group](https://jcsmr.anu.edu.au/research/groups/wen-group-computational-biology-rnas-and-functional-genomics) at the John Curtin School of Medical Research, The Australian National University, in Canberra.

I work on machine learning for single-cell perturbation screens: predicting how cells respond when a gene is perturbed, and using what is already known about genes to guide which experiments to run.

### How I like to work

- **Interpretable models first.** I want to know what a prediction rests on, not only how well it scores.
- **Baselines before models.** A method is worth what it adds to the simplest thing that works.
- **Everything from scripts.** Every number, table and figure is produced by code that anyone can rerun.

### Open work

[**EmbryoTempoFormer**](https://github.com/LijiayuDeng/s-biad531-embryo-tempoformer) is a reproducible pipeline that predicts developmental time from zebrafish time-lapse microscopy and estimates the tempo of each embryo, with data and checkpoints on [Zenodo](https://doi.org/10.5281/zenodo.18318139).

Current research code lives in private repositories and will be opened with the papers.
